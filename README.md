# 🎓 Student Management API
ប្រព័ន្ធ API សម្រាប់គ្រប់គ្រងទិន្ន័យនិស្សិត ដោយបង្កើតឡើងដោយប្រើប្រាស់ Java និង Gradle (Spring Boot ជាដើម)។

---

## 🚀 មុខងារសំខាន់ៗ (Features)
- 📋 បញ្ជីរាយនាម និងព័ត៌មានលម្អិតរបស់និស្សិត។
- ➕ បន្ថែម (Create) និស្សិតថ្មី។
- ✏️ កែប្រែ (Update) ព័ត៌មាននិស្សិត។
- ❌ លុប (Delete) ទិន្ន័យនិស្សិតចេញពីប្រព័ន្ធ។

---

## 🛠️ បច្ចេកវិទ្យាប្រើប្រាស់ (Tech Stack)
* **Language:** Java version 25
* **Build Tool:** Gradle
* **Framework:** Spring Boot version 4.1.2
* **Database:** PostgreSQL version 18
